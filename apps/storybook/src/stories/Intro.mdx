# ENITT Design System

**모니터링·관제 성격의 웹 화면**을 위한 도메인 중립 디자인 시스템입니다.

특정 업무 영역(전력, 공정, 물류, 서비스 인프라)에 묶이지 않습니다. 코어가 아는 것은 "상태에는 등급이 있다", "값에는 단위가 있다", "시계열에는 결측이 있다" 정도이고, 업무 개념은 이 위에 얹는 **도메인 팩**의 몫입니다.

## 패키지

| 패키지 | 역할 |
|---|---|
| `@enitt/tokens` | 디자인 토큰 단일 소스 (JSON → CSS 변수 + TS 상수) |
| `@enitt/core` | 공통 타입 · 포매터 · 기하 유틸 (React 무관) |
| `@enitt/ui` | 모니터링 화면용 React 컴포넌트 |
| `@enitt/charts` | SVG 차트 (스파크라인 · 시계열 · 게이지) |

## 설치

```bash
pnpm add @enitt/tokens @enitt/ui @enitt/charts
```

```tsx
// 진입점에서 한 번
import '@enitt/tokens/tokens.css';
import '@enitt/ui/styles.css';
import '@enitt/charts/styles.css';
```

## 도메인 확장

업무 개념은 코어에 넣지 않고 별도 패키지로 얹습니다.

- **타입** — `Severity` 를 재료로 도메인 상태 타입을 정의합니다.
- **토큰** — `@enitt/tokens` 의 `src/presets.json` 에 속성 프리셋을 추가하면
  `[data-enitt-<속성>='<값>']` 으로 켜지는 토큰 묶음이 생깁니다. 앱에서는
  `<ThemeProvider presets={{ '...': '...' }}>` 로 전달합니다.
- **컴포넌트** — 도메인 전용 렌더러는 자기 패키지에 둡니다.

전력 계통도(단선결선도)는 이 확장 방식의 첫 사례이며 `feature/diagram` 브랜치에서 별도로 진행 중입니다.

## 이 문서를 보는 법

위 도구 모음에서 **테마**(라이트/다크)를 바꿔 볼 수 있습니다. 두 테마는 자동 반전이 아니라 각각 따로 고른 값입니다.

## 설계 규칙

**상태를 색으로만 말하지 않습니다.** 심각도 배지는 등급마다 윤곽이 다른 아이콘(원·삼각형·마름모·팔각형)과 한국어 라벨을 함께 씁니다. 흑백으로 인쇄해도, 색각 이상이 있어도 읽힙니다.

**차트 계열 색은 고정 순서**로 배정하고 순환시키지 않습니다. 8슬롯 팔레트는 라이트·다크 표면 기준으로 검증돼 있습니다(인접쌍 CVD ΔE 9.1 / 8.4).

**y축은 하나뿐**입니다. 단위가 다른 지표는 차트를 나눕니다.

**결측은 결측으로** 그립니다 — null 구간에서 선이 끊깁니다.

**큰 숫자에는 `tabular-nums` 를 쓰지 않습니다.** 자릿수 정렬이 필요한 곳은 표와 축 눈금입니다.

**모션은 선택**입니다. 점멸 애니메이션은 `prefers-reduced-motion` 에서 정적 강조로 대체됩니다.
